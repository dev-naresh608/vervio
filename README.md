# Vervio

AI-generated interview speaking practice game.

Vervio helps you practice random interview topics with timed learning, speaking sessions, and local video recordings.

## Features

- Topic-based practice
- Easy / Medium / Hard difficulty
- Random topic shuffle
- 5 / 10 / 15 min learning sessions
- 1 / 2 / 3 min speaking sessions
- Camera & microphone recording
- Local recording storage
- Custom topic/category import
- No login or signup
- No server-side recording storage

## Tech Stack

React • Vite • JavaScript • Tailwind CSS

## Privacy

Recordings stay on the user's device and are not uploaded to a server.

## Status

Built as an AI-assisted project for interview preparation.
